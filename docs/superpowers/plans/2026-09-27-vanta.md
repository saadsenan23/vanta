# VANTA X1 Implementation Plan

Goal: implement the complete premium automotive campaign and interactive showroom in the existing starter.

Architecture: semantic React sections share data, motion primitives, CSS tokens and an accessible navigation shell. An isolated lazy R3F scene consumes configuration props and has an image fallback.

Tech stack: React, TypeScript, Vite, Tailwind, Motion, R3F, Three.js, Drei, Lucide, Playwright.

Spec: ../specs/2026-09-27-vanta-design.md

## Work checklist
- [x] Audit starter, assets and tools; establish design and component contracts.
- [ ] Build complete semantic campaign, navigation, responsive grid and motion system.
- [ ] Integrate original imagery, interactive scene, explorer and persisted configuration.
- [ ] Verify interactions, accessibility, breakpoints, reduced motion and failures; polish visuals.
- [ ] Run production checks and document architecture, assets and remaining limitations.

## Ownership
- Root: src/data, hooks, components/layout, sections, ui, motion, styles; build integration and report.
- Asset agent: public/images and docs/ASSETS.md.
- 3D agent: components/three and docs/THREE.md.
- QA agent: tests and playwright.config.ts.

## Review focus
1. Small screens retain all narrative content without overflow.
2. Invalid saved settings, unavailable storage, WebGL failure remain usable.
3. Dialog focus, Escape and menu navigation work with keyboard.
4. Motion reduction stops cinematic movement without hiding content.
5. All fictional specifications are labeled; no fabricated manufacturing claims.
